Yayasan Rumah Etnik Papua (REP) terus berkembang pesat dengan berbagai unit usaha
produktif seperti Yaswar Café, Toko Sovenir, Kios, Penyewaan Kostum, hingga Jasa
Fotografer. Seiring dengan peningkatan volume transaksi harian, pencatatan keuangan manual
(seperti menggunakan buku tulis atau spreadsheet dasar) menjadi sangat rentan terhadap
kesalahan manusia (human error), kehilangan data, dan memakan waktu yang lama untuk
rekapitulasi akhir bulan.
Sebagai bentuk kontribusi penuh selama program magang 1 bulan, saya telah merancang,
membangun, dan menyelesaikan aplikasi Sistem Informasi Keuangan (SIK-REP). Aplikasi
ini adalah perangkat lunak akuntansi berbasis Cloud (Awan) yang dibangun khusus dan
disesuaikan secara presisi dengan alur kerja Yayasan REP.

#TUJUAN DAN MANFAAT APLIKASI
Penerapan SIK-REP dirancang untuk mencapai target operasional berikut:
1. Otomatisasi Laporan Keuangan: Menghilangkan kebutuhan menghitung manual.
Laporan Buku Besar, Neraca Saldo, dan Laba Rugi tercipta secara real-time setiap kali
ada transaksi yang diinput.
2. Akurasi Standar Akuntansi: Menggunakan mesin Double-Entry Bookkeeping yang
menjamin keseimbangan (balance) antara Debit dan Kredit, mencegah hilangnya jejak
aliran dana.
3. Fleksibilitas (Bypass Method): Dilengkapi fitur Single-Entry khusus untuk
memudahkan input saldo awal tanpa mengganggu akun ekuitas/modal pemilik.
4. Aksesibilitas Tanpa Batas: Pimpinan yayasan dapat memantau saldo Kas, Pendapatan,
dan Biaya operasional kapan saja dan di mana saja melalui smartphone atau laptop.

#RUANG LINGKUP FITUR SISTEM
Aplikasi SIK-REP versi 1.0.0 (Production) yang telah selesai dibangun mencakup modul-
modul berikut:
1. Dashboard Eksekutif: Ringkasan real-time Total Kas Aktif, Pendapatan, dan
Pengeluaran bulan berjalan.
2. Jurnal Umum: Modul input transaksi harian dan pengaturan saldo awal (Kas, Piutang).
3. Buku Besar & e-Statement: Rincian mutasi per akun layaknya rekening koran
perbankan.
4. Neraca Saldo (Trial Balance): Laporan posisi saldo seluruh entitas aset, hutang, modal,
pendapatan, dan biaya.
5. Laba Rugi (Income Statement): Laporan kinerja finansial untuk mengukur
keuntungan/kerugian bersih unit usaha dengan filter periode
(Bulanan/Tahunan/Kumulatif).
6. Ekspor & Cetak Data: Fitur mengunduh laporan ke format CSV (Excel) dan cetak dokumen fisik (PDF/Kertas) dengan kop resmi Yayasan.
